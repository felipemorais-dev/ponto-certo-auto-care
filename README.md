# Ponto Certo Auto Care

Crie uma landing page completa, simples e responsiva para uma oficina mecânica fictícia chamada **Oficina Ponto Certo**, localizada em São Gonçalo, RJ. O site será usado somente como projeto de portfólio.

**Todos os dados são inventados.** Exiba um aviso visível no topo e no rodapé: “PROJETO DEMONSTRATIVO — empresa, serviços, preços, endereço e contato fictícios”. Não apresente a oficina como um negócio real e não crie depoimentos ou avaliações de clientes.

### Visual
- Aparência profissional, confiável e moderna.
- Paleta: grafite, branco, cinza metálico e laranja como cor de destaque.
- Layout limpo, fácil de ler e pensado primeiro para celular.
- Use fotos demonstrativas de oficina, mecânicos trabalhando e peças automotivas. Use imagens que possam ser usadas legalmente; não copie fotos de oficinas reais.
- Use ícones simples para representar os serviços.

### Conteúdo e seções

1. **Cabeçalho**
   - Nome “Oficina Ponto Certo”.
   - Links internos: Serviços, Sobre, Horários e Localização.
   - Botão “Pedir orçamento”, que leva à seção de contato ou abre o WhatsApp demonstrativo.

2. **Apresentação principal**
   - Título: “Cuidado e confiança para seguir caminho.”
   - Subtítulo: “Manutenção automotiva com atendimento claro e serviços para o dia a dia.”
   - Botão de destaque: “Pedir orçamento pelo WhatsApp”.
   - Imagem demonstrativa de uma oficina organizada.

3. **Sobre a oficina**
   - Título: “Sobre a Ponto Certo”.
   - Texto: “A Oficina Ponto Certo é uma empresa fictícia criada para esta demonstração de portfólio. Esta página ilustra como uma oficina poderia apresentar seus serviços e facilitar o contato de novos clientes.”
   - Não invente anos de experiência, certificações, garantias ou qualificações profissionais.

4. **Serviços e preços**
   - Identifique a seção como “Serviços e valores fictícios para demonstração”.
   - Crie cards com nome, breve descrição e preço:
     - **Revisão básica** — inspeção visual de itens essenciais do veículo. **A partir de R$ 180,00**.
     - **Troca de óleo e filtro** — serviço demonstrativo, com óleo e filtro sujeitos ao modelo do veículo. **A partir de R$ 150,00**.
     - **Inspeção do sistema de freios** — verificação de pastilhas, discos e componentes. **A partir de R$ 90,00**.
     - **Troca de pastilhas de freio** — valor demonstrativo, sujeito ao modelo do veículo e às peças necessárias. **A partir de R$ 220,00**.
   - Mostre uma observação abaixo dos preços: “Valores ilustrativos. O orçamento real depende do veículo, das peças e da avaliação do serviço.”
   - Cada card pode ter um botão “Consultar serviço”, levando ao WhatsApp demonstrativo com uma mensagem que inclua o nome do serviço.

5. **Galeria**
   - Monte uma galeria com fotos demonstrativas de oficina, ferramentas e serviços automotivos.
   - Não use imagens que pareçam comprovar trabalhos feitos pela oficina fictícia.

6. **Horários e localização**
   - Identifique as informações como fictícias.
   - Horário demonstrativo: segunda a sexta, das 8h às 18h; sábado, das 8h às 13h; domingo fechado.
   - Endereço demonstrativo: “Rua dos Motores, 123 — endereço fictício, São Gonçalo — RJ”.
   - Não incorpore mapa nem crie rota para esse endereço inventado. Mostre apenas o endereço como texto demonstrativo.

7. **WhatsApp demonstrativo**
   - Inclua um botão fixo de WhatsApp no canto inferior direito.
   - O botão deve abrir o WhatsApp com a mensagem pré-preenchida: “Olá! Gostaria de pedir um orçamento para [serviço]. Meu veículo é [marca, modelo e ano].”
   - Use apenas um número de teste claramente fictício como placeholder, centralizado em uma configuração fácil de substituir. Não use o número de uma empresa ou pessoa real. Mostre junto ao botão ou no aviso do site que o contato é demonstrativo.
   - Não crie formulário, sistema de agendamento, cadastro, pagamento ou armazenamento de dados.

### Requisitos finais
- Faça os links do cabeçalho rolarem até as seções correspondentes.
- Garanta que os botões e textos sejam legíveis em telas pequenas.
- Não invente avaliações, clientes, certificações, garantias ou resultados.
- Reforce que nome, endereço, contato, serviços e preços são fictícios.
- Gere a página completa, pronta para ser visualizada como demonstração de portfólio.
